# 勤務表自動生成ツール

本ツールは **Python + PuLP** を用いた数理最適化によって、病院間の勤務割り当てを自動で作成します。
勤務希望や病院側の指定日、最大勤務回数などを入力として、ハード制約を満たしつつソフト制約をできるだけ満たす勤務表を生成します。

GUIでは、設定ファイル（病院・勤務者・指定日・勤務回数上限）を**専用エディタ**で編集できます。
TOML/CSV を直接触る必要はありません。

> 作成者の勤務先で使用する私的ツールです。汎用的なツールではありません。

---

## 初期設定

**GUI版を使用する場合、複雑な初期設定は不要です。** GUI起動スクリプトが必要な環境を自動的にセットアップします。

### 簡単セットアップ（GUI版）

**Windows:**

1. `launch-gui.bat` をダブルクリック
2. 必要に応じてPythonとuvが自動インストールされます(初回は起動に時間がかかります)
3. 環境構築後、GUIが起動します

**macOS:**

1. `launch-gui.command` をダブルクリック
2. 必要に応じてuvが自動インストールされます（Homebrewまたは公式インストーラー）
3. 環境構築後、GUIが起動します

> **注意**: macOSでは初回実行時に「開発者を確認できません」と表示される場合があります。その場合は右クリック→「開く」を選択してください。

### 手動セットアップ（CLI版や開発者向け）

<details>
<summary>詳細な環境構築が必要な場合（クリックで展開）</summary>

1. **Python 3.13以上をインストール**
   - [Python公式サイト](https://www.python.org/downloads/) から最新版をダウンロード
   - インストール確認: `python3 --version`

2. **uvをインストール**

   ```bash
   pip install uv
   # または macOS の場合: brew install uv
   ```

3. **プロジェクトフォルダで依存関係をインストール**

   ```bash
   cd path/to/OptiRoster
   uv sync
   ```

</details>

## 使い方

### GUI版（推奨）

#### GUI起動方法

**Windows:**

1. `launch-gui.bat` をダブルクリック

**macOS:**

1. `launch-gui.command` をダブルクリック

> **注意**: macOSでは初回実行時に「開発者を確認できません」と表示される場合があります。その場合は右クリック→「開く」を選択してください。

**Linux:**

```bash
uv run -m src.gui.app
```

#### 画面構成

GUIは **メインタブ** と **設定タブ** の2つのタブで構成されています。

- **メインタブ**: 勤務希望CSVの選択 → 最適化実行 → Excel出力
- **設定タブ**: 各設定ファイルの専用エディタを起動するランチャー

#### GUIの使い方（メインタブ）

1. **勤務希望CSV選択**
   - 「勤務希望csv選択」ボタンをクリック
   - Google Formからダウンロードした勤務希望CSVファイルを選択

> [!NOTE]
> CSVファイルに同じ名前で複数のデータがある場合(後から勤務希望を送り直した場合)、
> 下の行にあるデータ(新しいデータ)が優先されます。

2. **処理実行**
   - 「処理実行」ボタンをクリック
   - 最適化処理が開始され、進行状況がログに表示されます
   - 処理完了時に結果の詳細（ペナルティ、人員不足等）が表示されます

3. **結果保存**
   - 「勤務表Excel出力」ボタンをクリック
   - 保存先を選択してExcelファイルを出力

#### 設定タブ

設定タブでは、各設定ファイルに対応した **専用エディタウィンドウ** を起動できます。
同じエディタの多重起動は自動的に防止されます（既に開いている場合はそのウィンドウが前面に表示されます）。

##### 毎月変更する設定

| ボタン | エディタ | 対象ファイル |
|--------|----------|--------------|
| 病院別勤務希望日 (specified-dates.toml) を編集 | 指定日エディタ | `data/specified-dates.toml` |
| 勤務回数上限 (max-assignments.csv) を編集 | CSVエディタ | `data/max-assignments.csv` |

##### 人事異動などがあった際に編集する設定

| ボタン | エディタ | 対象ファイル |
|--------|----------|--------------|
| 病院設定 (hospitals.toml) を編集 | 病院エディタ | `config/hospitals.toml` |
| 勤務者設定 (workers.toml) を編集 | 勤務者エディタ | `config/workers.toml` |

---

### 設定エディタの使い方

#### 病院エディタ（hospitals.toml）

病院の基本情報（名前、遠隔地フラグ、大学病院フラグ）と、各病院のシフト一覧（勤務形態・曜日・頻度）を編集します。

- **左パネル**: 病院一覧（並び順の変更、追加・編集・削除が可能）
- **右パネル**: 選択中の病院の詳細（名前、フラグ、シフト一覧）

**操作手順（病院の追加）:**

1. 「病院 新規追加」ボタンをクリック
2. ダイアログで病院名を入力し、遠隔地/大学病院のフラグを設定
3. 「シフト新規追加」でシフトを追加（勤務形態・曜日・頻度を選択）
4. 「OK」で確定
5. 「Save」で保存

**シフト設定の選択肢:**

- 勤務形態（shift_type）: `AM`, `PM`, `日勤`, `当直`
- 曜日（weekdays）: `月曜` ~ `日曜`（複数選択可）
- 頻度（frequency）: `毎週`, `隔週`, `指定日`

#### 勤務者エディタ（workers.toml）

勤務者の基本情報（名前、診断専門医フラグ）と、各勤務者のAssignment一覧（担当病院・曜日・勤務形態）を編集します。

- **左パネル**: 勤務者一覧（追加・削除が可能）
- **右パネル**: 選択中の勤務者の詳細（名前、専門医チェック、Assignment一覧）

**操作手順（Assignmentの追加）:**

1. 左パネルで勤務者を選択
2. 右パネルの「追加」ボタンをクリック
3. ダイアログで病院名・曜日・勤務形態を設定
   - 病院名は `hospitals.toml` に登録済みの名前がドロップダウンに表示されます
   - ドロップダウンにない病院名も手入力可能です（データは保持されます）
4. 「OK」で確定
5. 「Save」で保存

> [!NOTE]
> `hospitals.toml` に存在しない病院名がAssignmentに含まれている場合でも、データが消えることはありません。
> ドロップダウンの先頭に現在の値が表示され、そのまま保存できます。

#### 指定日エディタ（specified-dates.toml）

病院ごとの勤務指定日をカレンダー上でクリックして選択・解除します。

- **左パネル**: 病院リスト（追加・削除が可能）
- **右パネル**: カレンダー（指定日は黄色でハイライト表示）

**操作手順:**

1. 左パネルで病院を選択
2. カレンダー上で指定日をクリック（黄色に変わる）
3. もう一度クリックで解除
4. 「Save」で保存

> [!NOTE]
> カレンダーは起動時に翌月を表示します。月の切り替えはカレンダー上部の矢印で行います。

#### CSVエディタ（max-assignments.csv）

表形式で最大勤務回数を編集します。セルを直接編集できます。

- Delete キーまたは Backspace キーで選択セルをクリアできます
- 「Save」で保存

---

### 必要な設定ファイル

GUIを使用する前に、以下のファイルが適切に配置されている必要があります:

| ファイル | 説明 | 編集頻度 |
|----------|------|----------|
| `config/hospitals.toml` | 病院設定（名前、フラグ、シフト定義） | 人事異動時 |
| `config/workers.toml` | 勤務者設定（名前、専門医、担当病院） | 人事異動時 |
| `data/specified-dates.toml` | 病院別の指定日 | 毎月 |
| `data/max-assignments.csv` | 勤務者×病院の最大勤務回数 | 毎月 |

> [!NOTE]
> 対象月ごとにファイルを分けたい場合は、`data/specified-dates.toml` をコピー・リネームして編集した後、GUI用には最新の内容を `data/specified-dates.toml` に戻してください。

### CLI版（上級者向け）

<details>
<summary>コマンドラインでの詳細な制御が必要な場合のオプション（クリックで展開）</summary>

#### 短縮コマンド

```bash
uv run -m src.cli.main \
  -s data/specified-2025-10.toml \
  -p data/2025-10.csv \
  -a data/max-assignments.csv \
  -x output.xlsx
```

#### フルコマンド

```bash
uv run -m src.cli.main \
  --specified-days data/specified-2025-10.toml \
  --preferences data/2025-10.csv \
  --max-assignments-csv data/max-assignments.csv \
  --xlsx output.xlsx
```

> **注意**: 対象年月は勤務希望CSVのヘッダーから自動的に判定されます。

#### 利用可能な短縮オプション

**必須引数:**

- `-s, --specified-days` : 病院の勤務指定日TOMLファイル
- `-p, --preferences` : 勤務希望CSVファイル(対象年月はヘッダーから自動判定)

**オプション引数:**

- `-a, --max-assignments-csv` : 最大割り当て数CSVファイル
- `-H, --hospitals` : 病院設定TOMLファイル
- `-w, --workers` : 勤務者設定TOMLファイル
- `-x, --xlsx` : Excel出力パス
- `-j, --json` : JSON形式で出力

#### 毎月変更する部分

- `-s`/`--specified-days` を当該月の指定日ファイルに変更してください。
  (例: `data/specified-2025-11.toml`)
- `-p`/`--preferences` を当該月の勤務希望 CSV に変更してください。
  (Google Form からダウンロードした CSV をそのまま利用可。対象年月はCSVヘッダーから自動判定)
- `-a`/`--max-assignments-csv` を当該月の設定に合わせて編集してください。

#### 変更不要な部分

- `-H`/`--hospitals` (config/hospitals.toml)
- `-w`/`--workers` (config/workers.toml)
  これらはメンバーや病院の基本情報が変わらない限り編集不要です。

</details>

## 設定ファイル仕様

### hospitals.toml

病院の基本情報とシフト定義を格納します。

```toml
[[hospitals]]
name = "大学"
is_remote = false
is_university = true

[[hospitals.shifts]]
shift_type = "当直"
weekdays = ["月曜", "火曜", "水曜", "木曜", "金曜", "土曜", "日曜"]
frequency = "毎週"

[[hospitals]]
name = "鳥日赤"
is_remote = true
is_university = false

[[hospitals.shifts]]
shift_type = "日勤"
weekdays = ["火曜", "水曜", "金曜"]
frequency = "毎週"

[[hospitals.shifts]]
shift_type = "AM"
weekdays = ["木曜"]
frequency = "隔週"
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `name` | 文字列 | 病院名 |
| `is_remote` | 真偽値 | 遠隔地の場合 `true` |
| `is_university` | 真偽値 | 大学病院の場合 `true` |
| `shifts[].shift_type` | 文字列 | `AM`, `PM`, `日勤`, `当直` のいずれか |
| `shifts[].weekdays` | 文字列配列 | `月曜` ~ `日曜` から選択 |
| `shifts[].frequency` | 文字列 | `毎週`, `隔週`, `指定日` のいずれか |

### workers.toml

勤務者の情報と担当病院のAssignment定義を格納します。

```toml
[[workers]]
name = "藤井"
is_diagnostic_specialist = true

[[workers.assignments]]
hospital = "労災"
weekdays = ["金曜"]
shift_type = "日勤"

[[workers.assignments]]
hospital = "米医療"
weekdays = ["木曜"]
shift_type = "AM"

[[workers]]
name = "北尾"
is_diagnostic_specialist = true

[[workers.assignments]]
hospital = "大学"
weekdays = ["月曜", "火曜", "水曜", "木曜", "金曜", "土曜", "日曜"]
shift_type = "当直"
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `name` | 文字列 | 勤務者名 |
| `is_diagnostic_specialist` | 真偽値 | 診断専門医の場合 `true` |
| `assignments[].hospital` | 文字列 | 担当病院名 |
| `assignments[].weekdays` | 文字列配列 | 担当曜日（`月曜` ~ `日曜`） |
| `assignments[].shift_type` | 文字列 | `AM`, `PM`, `日勤`, `当直` のいずれか |

### specified-dates.toml

病院ごとの勤務指定日（日付番号のリスト）を格納します。

```toml
[[hospitals]]
name = "松日赤-治療"
dates = [12, 26]

[[hospitals]]
name = "安医"
dates = [5, 19]
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `name` | 文字列 | 病院名 |
| `dates` | 整数配列 | 指定日の日付番号（1~31） |

### max-assignments.csv

CSV形式で、1行目がヘッダー（勤務者名）、1列目が病院名、各セルが最大勤務回数です。
GUIのCSVエディタで表形式のまま編集できます。

## 制約

### ハード制約(必ず順守すべき制約)

違反がある場合、GUIのログで**赤色**で表示

- 各病院・各日に 1 人の勤務者を割り当てる
- 同日同時刻に複数病院へ勤務不可
- 勤務希望で「当直不可」「外勤・当直不可」の条件を満たす
- 大学病院の休日最終日の当直は診断専門医のみ
- 当直翌日の遠隔地勤務 (Day/AM) 禁止
- 最大勤務回数制限 (max-assignments.csv に基づく)

### ソフト制約(可能な限り順守する制約)

違反がある場合、GUIのログで**黄色**で表示

- 当直間隔をできるだけ広げる（連続禁止はハード制約で保証）
- 当直回数の偏りをできるだけ少なくする（休日の日当直は2回換算）
- 重み付なしの当直回数もできるだけ均等にする（当直3回の人と日当直1回の人が出ないように）
- 当直以外の勤務も曜日ごとに均等化
- 当直と遠隔地勤務(Day/PM) の同日割り当ては避ける
- 当直翌日の外勤を避ける（Day/AM の割り当てを回避）

## 隔月などの勤務への対応

### AさんとBさんが隔月で病院Xに交代勤務する場合

- 今月が A さんの月であれば:
  - `max-assignments.csv` で A さんの上限を枠数に設定（例: 1）
  - B さんの上限を 0 に設定
- 3 ヶ月に 1 回なども同様に設定可能

### 病院Xの金曜勤務者が4人おり、その月に金曜が5回ある場合

- A さんに 2 回入ってほしい場合:
  - `max-assignments.csv` で A さんを 2
  - 他の3人を 1 に設定
- 同様に勤務回数のバランスを調整する場合は`max-assignments.csv`で設定

### 大学当直を火曜・水曜限定にしたい場合

- `workers.toml` の該当勤務者の設定で

  ```toml
  weekdays = ["火曜", "水曜"]
  ```

### AさんとBさんで病院Yの毎週勤務を4~5回担当し、勤務日はAさんの希望を優先したい場合

- `勤務希望csv` で A さんの希望する場所以外を「外勤・」に設定
  - 例: 第1・2・5金曜日が希望の場合 -> 第3・4金曜日を「外勤・当直」に設定
- `max-assignments.csv` で病院Yの勤務回数を合わせて設定
  - 上記の場合、Aさんを 3、Bさんを 2 に設定

## 出力

### GUI版

- 処理結果がログウィンドウに表示されます
  - 最適化状況（制約数、変数数、求解時間等）
  - ペナルティ詳細（制約別の合計と上位項目）
  - 人員不足の詳細（病院・日付別）
- 「勤務表Excel出力」ボタンでExcelファイルを保存
  - A列: 日付、B列: 曜日、C列以降: 病院名
  - セル: 勤務者名（AM/PM は後ろに付与）
  - 休日行は薄いオレンジ色で塗りつぶし
  - 人員不足箇所は赤色で表示

### CLI版

- テキスト/リッチ表形式で割り当て結果とペナルティ内訳を表示
- `--xlsx` オプションでExcel出力（GUI版と同じ形式）
