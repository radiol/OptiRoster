# Project Rules

## Python tooling

- Use `uv` to run Python scripts, mypy, ruff, and pytest.
  - Examples: `uv run python ...`, `uv run mypy ...`, `uv run ruff ...`, `uv run pytest ...`

## Git hooks

- Manage git hooks with `lefthook`.

## Changelog

- Generate CHANGELOG with `git-cliff`.

## Development tool installation

- Install development tools (lefthook, git-cliff, etc.) with `mise`.
